# TAYEEBA HOUSING LTD. ERP v2.6 — Supabase Storage & Document Vault

---

## 1. Bucket Structure & Privacy Rules

All document storage buckets in Supabase are **PRIVATE** by default:

| Bucket Name | Purpose | Access Control |
|---|---|---|
| `customer-documents` | Customer NIDs, photos, nominee documents | Private. Requires signed URL generated by backend. |
| `project-documents` | Master project layout plans, brochures, approvals | Private. Requires signed URL. |
| `land-documents` | Khatians, deeds, mutation certificates, vetting reports | Private. Requires signed URL. |
| `employee-documents` | National IDs, academic certificates, signed contracts | Private. Requires signed URL. |

---

## 2. Secure Upload & Download Lifecycle

1. **Upload**: Client uploads file to `/api/documents/upload` via `multipart/form-data`.
2. **Server Validation**: The Express API validates file extension (whitelist: `.pdf, .jpg, .png, .doc, .docx, .xls, .xlsx`) and file size (max 10MB).
3. **Storage & Metadata**: File is saved to private Supabase bucket with sanitized UUID key; metadata recorded in `document` table.
4. **Download**: Client requests signed download URL. Express verifies RBAC permission and returns a signed URL with 60-second TTL.
